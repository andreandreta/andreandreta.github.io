Tools for learning power inverters

Five interactive lessons: the Clarke transform, space vector modulation and the spectrum of an RL load, then two games where you play the modulator and the current controller.
The inverter can only produce 8 switching states: 6 active vectors at the corners of a hexagon and 2 zero vectors at the centre. To produce any reference vector inside the hexagon, SVM applies the two neighbouring active vectors and a zero vector during each switching period Ts, for durations chosen so that their average equals the reference.
Key idea

Vref = (T1/Ts)·Vk + (T2/Ts)·Vk+1, and the zero vectors fill the rest of Ts. The orange and blue arrows on the diagram show this sum. In the linear range (m ≤ 1, inside the dotted circle), the average pole voltage follows a “saddle” shape that stays within ±Vdc/2. This is why SVM gives 15% more output voltage than sine PWM.

Try it
  1. Move θ from 0° to 60°. How do T1 and T2 change? What happens at 30°?
  2. Set m = 1. In the waveform panel, the phase a reference goes beyond ±Vdc/2 but the average pole voltage does not. Why is that allowed?
  3. Look at the 7-segment sequence in sectors 1 and 2. How many legs change state at each step?

Clarke transform / three phase values to a stationary planeINSTANTANEOUS VOLTAGES · V
Each phase value lies on its own axis, separated by 120°. Project the three values onto the stationary α and β axes, then add those contributions. The zero-sequence component v0 (the average of the three phases, also called common mode) is shown separately because it does not change the αβ vector.
Key idea

Three phase values can be replaced by one vector in the (α, β) plane plus a zero-sequence component v0. For a balanced three-phase set, v0 = 0 and the vector turns at the electrical frequency with a constant length equal to the phase amplitude.

Try it
  1. Press “Rotate a balanced set”. Does the length of the αβ vector change during a turn?
  2. Click “+25 V on all phases”. Which values change: vα, vβ or v0?
  3. Set va = 100 V and vb = vc = −50 V. Predict vα and vβ before reading them.
  4. On the time plot, compare vα with va. What is the phase shift between vα and vβ?

Zero-sequence component

Recover the phase values: va = vα + v0,   vb = −½vα + √3⁄2 vβ + v0,   vc = −½vα − √3⁄2 vβ + v0.
For a balanced three-wire set, va + vb + vc = 0, so v0 = 0. Adding the same value to all three phases changes only v0 and leaves the αβ vector unchanged.
Convention: Clarke or Concordia?
This page uses the amplitude-invariant Clarke transform (factor 2/3): the αβ vector has the same length as the phase amplitude. The power-invariant Concordia transform uses √(2/3) instead of 2/3. The vector is then √(3/2) ≈ 1.22 times longer, but its direction and the reasoning stay the same.
PWM output spectrum / RL phase load50 Hz FUNDAMENTAL · IDEAL TWO-LEVEL INVERTER
See the inverter's phase-to-neutral voltage spectrum and the current spectrum after a series R-L load. Adjust the load and carrier frequency; the switching-frequency bands move with fs while inductance attenuates high-frequency current ripple.
Key idea

The inverter voltage is a series of pulses: its spectrum contains the 50 Hz fundamental plus bands of harmonics around multiples of fs. The RL load acts as a low-pass filter: the higher the frequency, the more the inductance opposes the current. So the current is almost sinusoidal even though the voltage is not.

Try it
  1. Switch between Voltage and Current. Why are the two THD values so different?
  2. Double fs. Where do the harmonic bands move, and what happens to the current THD?
  3. Double L. Predict the effect on the current ripple, then check it in the time-domain plot.

Human modulator / rotating voltage reference30 SECOND ROUND · ROTATING αβ REFERENCE
What if you were the modulator? Take control of a three-phase inverter and choose its switch state in real time. Each key applies one of the 8 voltage vectors. Like a real modulator, combine the vectors so that their average over each switching period Ts follows the rotating αβ reference. Numpad: 6 → V1 · 9 → V2 · 7 → V3 · 4 → V4 · 1 → V5 · 3 → V6 · 5 → V0 · 8 → V7. Press Start round, then use the numpad.
Key idea

A modulator never simply holds the nearest vector. It alternates quickly between the two neighbouring active vectors and a zero vector so that their average over each switching period Ts follows the reference. Your score measures exactly that average.

Try it
  1. Play one round holding only the nearest vector. Play again alternating with V0 or V7. Compare the scores.
  2. Set m = 1. Do you still need the zero vectors, and when?
  3. Increase Ts. Is the game easier? What would a longer Ts mean for a real inverter?
  4. In the Va, Vb, Vc view, which levels can a switched phase voltage take? Express them as fractions of Vdc.

Grid current control / single-phase full bridge50 Hz GRID · ONE CYCLE IN 20 S
Inject current into the grid. Command the full bridge to apply positive voltage, zero voltage, or negative voltage. Track the reference current without crossing the overcurrent limit. More inductance gives the current more inertia and makes it easier to steer. Careful: 0 V does not freeze the current, because the grid voltage keeps driving it.
Key idea

The bridge can only apply +Vdc, 0 or −Vdc. The inductance turns the voltage difference into a current slope: L·di/dt = vbridge − vgrid (resistance neglected). With 0 V applied, L·di/dt = −vgrid: the current keeps moving.

Try it
  1. Near the peak of the grid voltage, apply 0 V. Which way does the current go?
  2. Near the same peak, compare the current slope with +Vdc and with −Vdc. Why is it much smaller with +Vdc?
  3. Play with L = 5 mH, then L = 25 mH. Which one is easier to control, and which one gives the lower THD?
