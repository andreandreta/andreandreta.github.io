Common-mode component
v0 = ⅓ [va + vb + vc]
Recover the phase values: va = vα + v0,   vb = −½vα + √3⁄2 vβ + v0,   vc = −½vα − √3⁄2 vβ + v0.
For a balanced three-wire set, va + vb + vc = 0, so v0 = 0. A common-mode shift moves all three phase values equally but leaves the αβ vector unchanged.
